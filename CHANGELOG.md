- Block selection for code, quotes, and standalone inline code, plus optional tool calls and outputs.
- `/copy-block` and `Ctrl+Shift+B` to copy the latest assistant block or message.
- Direct TypeScript package, package contract checks, and guarded tag-based publishing.
